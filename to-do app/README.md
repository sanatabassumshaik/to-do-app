# 📝 To-Do List Application

A responsive, client-side To-Do List application built with HTML5, CSS3, and JavaScript.

This project demonstrates DOM manipulation, event handling, state management, CRUD operations, event delegation, filtering, and browser-based data persistence using `window.localStorage`.

---

## 🚀 Features

- ➕ Create new tasks
- 📋 Display all tasks dynamically
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔄 Toggle task completion status
- 🔍 Filter tasks:
  - All
  - Active
  - Completed
- 🧹 Clear all completed tasks
- 💾 Automatically save tasks using `window.localStorage`
- 🔄 Restore tasks automatically after refreshing the browser
- 📱 Responsive design for different screen sizes
- ⚡ Dynamic DOM rendering
- 🎯 Event delegation for task actions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Events
- `window.localStorage`
